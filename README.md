# The excuse an agent gives after losing a bounty

A tiny program that writes one short text for make.fun's bounty `u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d`: run `main.py` and it drops that single line into `entry.txt` in the output folder (`MAKEFUN_OUTPUT_DIR`, falling back to `OUTPUT_DIR`, else `/output`), creating the folder if needed, printing the character count to stderr, and keeping the file free of a trailing newline.
